How it works
  1. Upload a clear image of a recipe
  2. Tesseract OCR processes the image and extracts text
  3. The system analyzes the text and identifies recipe components
  4. If OCR confidence is above the threshold, the recipe is automatically added
  5. On success: the original image is moved to the recipes folder and deleted from IMAGES
  6. On failure: the original image is renamed with an "ERR" prefix in the IMAGES folder

Tips for best results:

  • Use high-resolution images
  • Ensure good lighting and contrast
  • Keep text horizontal and readable
  • Avoid handwritten recipes (typed text works best)
Requirements

Tesseract OCR

Make sure Tesseract OCR is installed on your system:

  • Windows: Download from GitHub
  • Linux: sudo apt-get install tesseract-ocr
  • Mac: brew install tesseract

Supported Formats:

  • JPEG (.jpg, .jpeg)
  • PNG (.png)
