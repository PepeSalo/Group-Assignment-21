How it works
  1. Upload a recipe image, paste a URL, or both
  2. If an image is provided, Tesseract OCR extracts text and detects URLs
  3. If a URL is provided (or found in the image), the page is scraped for recipe data
  4. Recipe data from OCR and URL scraping are intelligently combined
  5. If the recipe is new, it is created automatically
  6. If a matching recipe exists, empty fields are auto-filled, and you are asked before overwriting existing data
  7. Image files: on success, deleted from IMAGES folder; on failure, renamed with "ERR" prefix

Tips for best results:

  • Use clear, high-resolution images
  • For best results, paste the recipe URL directly
  • Images containing visible URLs will be automatically detected and scraped
  • Enable "Search web" to find additional data from detected URLs
Supported Input

Image Files (OCR)

  • JPEG (.jpg, .jpeg)
  • PNG (.png)

Recipe URLs

Paste any recipe URL. Best results with sites using structured data (JSON-LD). Works with most recipe sites including:

  • Recipe blogs and cooking sites
  • News articles with recipes
  • Finnish recipe sites (kotiliesi.fi, etc.)
  • International recipe sites

Data Protection

Existing recipe data is protected. If scraped data conflicts with existing data, you will be asked to confirm before any changes are made.
